# GHL module map

| GHL area | Schema in v0 SQL | UI / API |
| --- | --- | --- |
| Sub-accounts + users | Yes | Phase 0 (auth, locations, `X-Location-Id`) |
| Contacts, companies, tags, custom fields | Yes (custom fields table only) | Phase 1 UI for contacts / companies / tags |
| Opportunities / pipelines | Yes | Phase 1 board + move |
| Tasks, notes, calendar | Yes | Phase 2 |
| Conversations (email first) | Yes | Phase 2 |
| Workflows | Yes | Phase 3 |
| Forms | Yes | Phase 3 |
| Funnels / sites / memberships / payments / SMS / reputation | Tables stub or skip | Later |

Phase 0–1 is what you can log into and use like a small GHL.
